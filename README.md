## 💡 Overview

This repository contains step-by-step implementations for 30 fundamental Python problems. Every exercise is implemented with modular functions and interactive `input()` mechanisms to allow real-time console testing.

---

## 🛠️ Concepts Covered

- **Control Flow:** `if-else`, `if-elif-else`, `while` loops, `for` loops, nested loops
- **Arithmetic & Logic:** Modulo (`%`), integer division (`//`), ASCII character conversion, square root operations
- **String Manipulation:** Indexing, slicing (`[::-1]`), string traversal, character frequencies, manual parsing without standard built-ins (`len()`, `split()`, `max()`)
- **Functions:** Declarations, parameter handling, explicit return statements

## 📂 List of Exercises

### Section A – Basic Control Structure & Numbers (1–10)
1. **Even or Odd** – Checks if a given integer is even or odd using `%`.
2. **Positive, Negative, or Zero** – Categorizes numbers using conditional checks.
3. **Find Largest of Two Numbers** – Evaluates and returns the maximum of two numbers.
4. **Find Largest of Three Numbers** – Compares three values without using `max()`.
5. **Sum of Natural Numbers** – Computes the sum from $1$ to $n$ using a `for` loop.
6. **Multiplication Table** – Displays multiplication output up to $10$.
7. **Factorial Using Function** – Iteratively calculates $n!$ without recursion.
8. **Count Digits** – Calculates total digits in an integer using integer division (`//`) and a `while` loop.
9. **Reverse a Number** – Reverses digits mathematically using `%` and `//`.
10. **Prime Number Check** – Determines primality using trial division up to $\sqrt{n}$.

### Section B – String Processing & Analytics (11–20)
11. **Count Characters in a String** – Counts total length manually without using `len()`.
12. **Count Vowels** – Identifies vowel frequencies in text.
13. **Count Consonants** – Filters and tallies alphabetic non-vowel characters.
14. **Count Vowels and Consonants** – Outputs separate counts for vowels and consonants.
15. **Reverse a String** – Reverses input strings via loop accumulators and slicing (`[::-1]`).
16. **Check Palindrome String** – Assesses string symmetry.
17. **Count Words** – Calculates word count manually without `split()`.
18. **Find Frequency of a Character** – Measures character occurrences without `count()`.
19. **Remove Spaces** – Strips whitespace using loop iteration without `replace()`.
20. **Convert Lowercase to Uppercase** – Explores string casing via `.upper()` and ASCII math (`ord`/`chr`).

### Section C – Advanced String Manipulation (21–28)
21. **Count Uppercase and Lowercase Characters** – Segregates counts for uppercase, lowercase, digits, and spaces.
22. **Find First Character** – Extracts initial character using early loop `break` without indexing.
23. **Find Last Character** – Demonstrates last character retrieval via `-1` index and loop traversal.
24. **Print Each Character** – Displays individual string elements line-by-line.
25. **Print Characters with Position** – Displays character indices along with values using `range()`.
26. **Remove Vowels** – Filters out vowels without using string `replace()`.
27. **Find Longest Word** – Finds maximum length word without `max()`, dictionaries, or advanced modules.
28. **Count Occurrence of Each Vowel** – Separately counts individual vowel frequencies (`a`, `e`, `i`, `o`, `u`).

### Section D – Patterns & Nested Loops (29–30)
29. **Star Pattern** – Prints a right-angled triangle star pattern for $n$ rows.
30. **Number Pattern** – Generates sequential number pyramids using nested `for` loops.
